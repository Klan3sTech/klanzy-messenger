# Klanzy × M3E — мессенджер на Material 3 Expressive

## Что сделано и как

### 1. Логика осталась исходной

`src/App.tsx` — это **ваш исходный файл** (4045 строк): те же состояния, обработчики и запросы
к `server/index.mjs`. Ни одна функция не удалена и не переписана:

- регистрация (ник, @username, почта, аватар, лайт-режим) и **вход по коду** + **QR-вход между устройствами**;
- **Klanzy AI**: поля `Gemini API Key` и `Модель` (Настройки → Профиль → блок «Klanzy AI»), офлайн-режим без ключа;
- поиск с вкладками Чаты / Каналы / Видео / Фото / Файлы / Загрузки, менеджер загрузок;
- эвенты, чаты, каналы, группы, боты, подписки, закреплённые сообщения, ответы, удаление, вложения и просмотр медиа;
- устройства и сессии (список, отзыв одного/всех, отзыв по пользователю);
- админка `@klan3s`: пользователи, бейджи, баны, удаление, рассылка в любой чат, админы группы, удаление группы/канала;
- темы (тёмная/светлая), 8 акцентных палитр, лайт-режим, блокировки, бейджи.

Единственные вставки в `App.tsx`:

| Что | Зачем |
|---|---|
| `import { M3eTheme } from "@m3e/react/theme"` + `@m3e/web/*` | подключение настоящих веб-компонентов M3E |
| обёртка `<M3eTheme variant="tonal-spot" motion="expressive" scheme={theme} color={seed}>` | M3E считает всю палитру из seed-цвета акцента |
| `readM3Tokens()` | читает `--md-sys-color-*` из темы и отдаёт их в `accent.*` (тот самый объект, которым приложение красило кнопки, панели, пузыри) |
| смена значений в 10 объектах стилей (`pageBackgroundStyle`, `panelStyle`, `accentButtonStyle`, `accentBubbleStyle`, `accentMineMessageStyle`, …) | вместо хардкод-hex теперь токены M3 |
| новый `export default function App()` | обёртка-тема, реагирует на смену темы/акцента событием `klanzy:skin` |

### 2. Палитра — из M3E, а не «на глаз»

Каждый из 8 акцентов — это **seed-цвет**, из которого M3E генерирует полный набор токенов
(`primary`, `on-primary`, `surface-container-*`, `outline-variant` …) отдельно для dark и light:

| Акцент | Seed |
|---|---|
| Кланзи | `#6750A4` |
| Мандарин | `#B4501B` |
| Яблоко | `#2E6B3E` |
| Клубника | `#B3261E` |
| Лимон | `#7A5900` |
| Океан | `#00639B` |
| Орхидея | `#8A4585` |
| Графит | `#5B5D72` |

Поэтому переключение «Тёмная/Светлая» и акцента перекрашивает всё приложение сразу — включая
пузыри сообщений, кнопки, панели и рамки, без правки разметки.

### 3. Слой оформления `src/styles/m3e-skin.css`

Тонкий CSS-слой поверх Tailwind, который переводит старые нейтральные классы в M3:

- `text-slate-*` → `on-surface` / `on-surface-variant`;
- `bg-slate-900` → `surface-container-low` и т.д.;
- поля ввода — M3 filled-стиль (скругление 16px, `surface-container-highest`, фокус 2px primary);
- кнопки — пилюли, state layer при наведении, `scale(.975)` при нажатии, focus-ring;
- деструктивные кнопки — `error-container` / `on-error-container`;
- радиусы по шкале M3 (12 / 16 / 28 px), скроллбары Material, `::selection` в primary-container;
- заголовки — medium-вес M3 с отрицательным трекингом.

`motion="expressive"` включает экспрессивные кривые M3E; старые анимации (`klanzy-panel-enter`,
`klanzy-message-enter`…) остались, лайт-режим их по-прежнему отключает.

## Запуск

```bash
cd klanzy-m3e
npm install

# терминал 1 — бэкенд (нужен Node 22+: используется node:sqlite)
npm run server      # http://localhost:3001

# терминал 2 — фронтенд (Vite проксирует /api и /ws на :3001)
npm run dev         # http://localhost:5173
```

Прод-сборка: `npm run build` → `dist/index.html` (single-file, ~633 КБ / 161 КБ gzip).
Раздача: статика + прокси `/api` и `/ws` на бэкенд.

```nginx
location / { try_files $uri /index.html; }
location /api/ { proxy_pass http://127.0.0.1:3001; }
location /ws {
  proxy_pass http://127.0.0.1:3001;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
}
```

## Быстрая проверка возможностей

1. **Регистрация** → ник, `@klan3s`, почта, аватар → «Войти в Klanzy». `@klan3s` — владелец, у него в Настройках появляется вкладка **Админ**.
2. **Вход** (вторая вкладка на экране входа) → «Вход по коду»: `@username` + 6-значный код, и «Сгенерировать QR для входа» — вход между устройствами.
3. **Настройки → Профиль** → внизу блок **Klanzy AI**: `Gemini API Key` + `Модель` (без ключа — офлайн-ответы).
4. **Настройки → Профиль** → «Получить код» (вход на другом устройстве) и список устройств с отзывом сессий.
5. **Настройки → Темы** → тёмная/светлая, лайт-режим, 8 палитр (все на токенах M3E).
6. **Поиск** → вкладки Чаты / Каналы / Видео / Фото / Файлы / Загрузки.
7. **Чат** → правый клик или долгое нажатие на сообщении: ответ, закрепление, удаление; «+» — вложение.
8. **Gemini-чат** — вопросы боту, при ключе отвечает реальный Gemini API.

Скриншоты: `shots/m3-01-auth`, `m3-02-login`, `m3-03-chats`, `m3-04-message`, `m3-05-search`,
`m3-06-events`, `m3-07-themes`, `m3-08-light`, `m3-09-light-chats`, `preview-desktop`, `preview-admin`, `preview-gemini`.

## Приватность групп и каналов

Сделано по запросу: **группы и каналы видит только их создатель**, и только он управляет админами.

| Где | Что изменилось |
|---|---|
| `src/App.tsx` | `visibleChatList` фильтрует `group`/`channel` по `ownerUsername === текущий пользователь`; боты и личные диалоги видны всем |
| `src/App.tsx` | `canManageActiveChat` = «я создатель» (раньше: создатель **или** админ чата **или** глобальный админ) |
| `src/App.tsx` | поиск (`searchableEntities`) использует то же правило — чужие группы/каналы не всплывают в выдаче |
| `src/App.tsx` | клик по **названию** группы/канала открывает меню управления: список админов, выбор пользователя, «Назначить» / «Снять», «Удалить группу/канал». Встроенная панель из шапки чата убрана — теперь всё в меню |
| `server/index.mjs` | `/api/bootstrap` отдаёт группы и каналы **только их создателю** (фильтрация на сервере, а не только в интерфейсе) |
| `server/index.mjs` | `hasChatAdminRights()` теперь пускает **только владельца** чата (глобальный админ и назначенные админы больше не управляют чужими группами/каналами) |
| `server/index.mjs` | сид-чаты (`Общий чат Klanzy`, `Канал Klanzy`) получили создателя `@klan3s` |

Как проверить: зайти как `@klan3s` → видны «Общий чат Klanzy» и «Канал Klanzy»; зайти любым другим аккаунтом → в списке только бот и Gemini.
Новая группа, созданная любым пользователем, видна только ему.

## Переименование Minx → Klanzy

Заменено во всех слоях, консистентно (клиент ↔ сервер):

| Было | Стало |
|---|---|
| `Minx` в текстах, заголовках, письмах | `Klanzy` |
| `@MinxCommunity`, `@MinxSupport`, `@MinxGemini`, `@Minx` | `@KlanzyCommunity`, `@KlanzySupport`, `@KlanzyGemini`, `@Klanzy` |
| id чатов `minx-community`, `channel-minx` | `klanzy-community`, `channel-klanzy` |
| ключи localStorage `minx_profile`, `minx_theme`, `minx_gemini_api_key` … | `klanzy_*` |
| CSS/анимации `.minx-fade-in`, `minxPanelEnter` … | `.klanzy-fade-in`, `klanzyPanelEnter` … |
| QR/пейринг-параметры `minx_user`, `minx_code`, `minx_pair` | `klanzy_user`, `klanzy_code`, `klanzy_pair` |
| БД `server/data/minx.sqlite` | `server/data/klanzy.sqlite` |
| пакет `minx-m3e` | `klanzy-m3e` |
| аватар-заглушка и favicon «M» | «K» |

⚠️ Два следствия: локальные настройки в браузере (тема, профиль, ключ Gemini) начнутся с чистого листа,
и база создаётся заново — `@klan3s` нужно зарегистрировать один раз после переименования.

## Файлы

```
src/App.tsx                 # ваш исходный мессенджер + обёртка <M3eTheme> и токены
src/index.css               # исходный CSS + @import скина
src/styles/m3e-skin.css     # ← весь новый дизайн
src/main.tsx                # без изменений
server/index.mjs            # без изменений
reference/m3e-redesign/     # архивная полная переделка на компонентах <m3e-*> (для справки, не подключена)
```

> `reference/m3e-redesign` — это другой путь (полный рерайт UI на `<m3e-button>`, `<m3e-dialog>` и т.п.),
> он красивее «по компонентам», но в нём меньше функций. Сейчас приложение работает на вашем коде,
> поэтому выбран вариант «функционал ваш + оформление M3E».
